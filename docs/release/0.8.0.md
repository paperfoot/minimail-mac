# Minimail 0.8.0

## Changes

Minimail expands from its compact menu-bar view into a resizable three-column mail window. Both presentations share the same mailbox and draft state. Closing the window returns to menu-bar operation. The status-item context menu includes Open Window, New Message, Check Mail, Settings, and Quit.

Settings now groups account/profile management, signatures, delivery recovery, and advanced options. The release also repairs draft metadata and attachment persistence, Undo Send, account/search races, pagination, reply/forward content, long HTML rendering, and mailto handling.

The [client audit](../client-audit-2026-09.md) records the source-reading workflow, independent review passes, open-source comparisons, fixes, and remaining product work.

## Validation

- 49 Swift tests in eight suites passed.
- 65 Rust tests passed; the documented strict Clippy command passed.
- All 16 build and bundled-helper checks passed against isolated data.
- Separate visual review passed the corrected Settings layout and the minimum-size 960 × 580 full → compact → full compose transition.
- The synthetic draft retained its recipient, subject, and body in both presentations and the fixture database. No real delivery was used for QA.
- UI automation could not reliably focus SwiftUI controls; typing and account CRUD dialogs remain manual UI acceptance checks.
