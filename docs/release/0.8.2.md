# Minimail 0.8.2 verification receipt

Released on October 14, 2026. First public release since 0.7.1; it ships the 0.8.0 and 0.8.1 work, which were only installed locally while notarization was unavailable.

## Changes

- The menu-bar popover stays under its icon. Before, display changes (plugging in or removing a screen, closing the lid, sleep/wake, resolution or Space changes) left it stranded, sometimes over the menu bar with its header off-screen. Clicking the icon now snaps a drifted popover back; clicking it again closes it.
- Everything in [0.8.0](0.8.0.md) and [0.8.1](0.8.1.md).

## Automated verification

- `scripts/verify.sh`: 16 checks passed, zero failures.
- Swift Testing: 72 tests across 11 suites passed.
- The release build embeds email-cli 0.7.7 from the sibling source checkout (unchanged since its published release).

## Native acceptance

- A temporary virtual display made main for this process (as when a lid opens or a laptop is plugged in): the 0.8.1 popover was left at y=-1153, above every screen; the 0.8.2 popover followed the icon to the new main display and back when the display was removed.
- Adding and removing a secondary display left the 0.8.2 popover anchored throughout.
- Moving the icon in the menu bar with the popover open: the popover followed it.
- 14 consecutive icon clicks alternated open and close correctly.
